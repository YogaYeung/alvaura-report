Implementation Playbook · 实操落地指南

照着做：每一条都有"现在这样 → 改成这样"的示意图

站点是 Shopify + Ella 主题 7.1.0 + Judge.me。下面每条动作都配了两张图：左边是网站现状（红框标出问题位置），右边是把建议直接"画"在 alvaura.com 真实页面上的效果示意——改在哪、改成什么样，看图就知道。90% 的动作在 Shopify 后台和主题编辑器完成，不需要写代码；英文文案可直接复制。

示意图说明：右侧"改成这样"是在真实页面上叠加建议元素后截图，用于表达位置与内容；具体视觉样式以主题实现为准。

术语速查
主题编辑器
Shopify 后台 Online Store → Themes → Customize，拖拽区块改首页/详情页的地方。
Metafield
Shopify 给商品加自定义字段（如"克拉数"），主题可以读出来显示。
Tag
商品标签，用来自动归集合和显示卡片角标。
Shopify Bundles
Shopify 官方免费套装应用。
Klaviyo / Shopify Email
邮件营销工具，都有免费档；弹窗收邮箱 + 自动发欢迎码。
Judge.me
Alvaura 已装的评价插件，支持自动邀评邮件和带图评价奖励。
Sticky add-to-cart
手机端滚动时固定在屏幕底部的加购条。

第一档 · P0（两周内，不用开发）

1. 首屏换成主力款 + 明确按钮 + 公告栏改信任信息

现在

① COMING SOON 按钮没有链接，推的是买不到的款；② 公告栏承诺 15% 但全站无领取入口。

改成这样

首屏换成 Vivid Mint 星座戒的手部实拍（甲方确认的反响最好款），眉标点名 VIVID MINT · 2.6 CT，标题 Color, at full size.，按钮直达该款详情页；公告栏改成四条信任信息。

1
后台 Online Store → Themes → Customize → 首页 → Slideshow 区块：图换成 Vivid Mint Green Constellation Cluster Ring（甲方确认的反响最好款）的手部实拍——现有商品图第 2 张（手靠近脸、薄荷绿主石 + 叠戴）可直接用，横幅裁切时把戒指放在画面中部偏左。
2
文案：Eyebrow Real lab-grown sapphires · 2–4 ct；Heading Color, at full size.；Sub Big, vivid gemstones in 2.5-micron 14k gold vermeil — the size mined stones can't give you under $400.；Eyebrow 也可直接点名 Vivid Mint · Real lab-grown sapphire · 2.6 ct；Button 1 Shop Vivid Mint — $259 → 该产品详情页；Button 2 Shop by Color。
3
Announcement bar 改为 4 条轮播：Get 15% off your first order — join the list / Duties & taxes included · Free shipping over $150 / 2.5-micron 14k gold vermeil · 2-year Brilliance Warranty / Real lab-grown sapphires & spinels · 2–4 ct center stones。GEM STACKER 移到第二屏做 "Notify me"。
✓
验证：手机打开首页，第一屏能看到一个可点击的 Shop 按钮，点进去是有商品的页面。

2. 首单 15% 闭环：弹窗收邮箱 → 自动发码

现在

公告栏写了 15%，结账时小计等于总计，没有任何地方能领到这 15%。

改成这样

首次访问 8 秒后弹出：左图主力款，右侧标题 + 邮箱框 + 按钮，小字说明 WELCOME15 邮件送达、每人一次。

1
Shopify 后台 Discounts → Create discount → Amount off order → 15% → Code WELCOME15 → 勾选 "Limit to one use per customer"。
2
装 Shopify Email（免费）或 Klaviyo：建 Sign-up form 弹窗，触发"首次访问 8 秒后或滚动 40%"，提交后自动发邮件含 WELCOME15。
✓
验证：无痕窗口访问 → 弹窗出现 → 填邮箱收到码 → 结账输入码总价减 15%。

3. 清理空集合，颜色菜单做成"色块 + 款数"

现在

9 个颜色入口里 4 个（Morgan Pink / Padparadscha / Paraiba / Cornflower）点进去是 "No products found"；NEW 也是空页。

改成这样

每个颜色配色块 + 右侧款数，没有商品的入口不出现；商品按 tag 自动归进颜色集合。

1
Products → Collections：Paraiba Blue / Padparadscha Peachy Pink / Cornflower Blue / Morgan Pink 改成自动集合（条件 "Product tag equals color:paraiba" 等），给对应在售商品打 tag（Paraiba 2 款、Padparadscha 1 款、Cornflower 2 款、Morganite 2 款）。
2
删除 best b、Gem - $269 / $289 / $389 四个测试集合；Online Store → Pages 删除 size-guide的副本。NEW 集合改自动条件 "Created date is after [90 天前]"。Asscher / Marquise / Ruby / Hidden Diamonds / Gift Picks / New Gemstones 暂无商品的先从 Navigation 移除。
3
Navigation → 主菜单 Shop by Color：Ella 主题支持菜单项图标/色块（Customize → Header → Mega menu → 每项上传 24×24 色块图）；款数可在菜单文案里手填。
✓
验证：逐个点导航所有二级项，没有一个显示 "No products found"。

4. 重写运费 / 退货政策，四处口径统一

现在

正式政策写"中国仓直发、关税客户自理"，结账页却是"关税已含"；退货页还是 Shopify 模板。

改成这样

按结账页实际口径重写：标准 $7.90 满 $150 免、关税已含；快递 $19.90 满 $300 免；现货 1–3 天、定制 7–15 天；30 天退；hello@alvaura.com 24 小时回复。

1
Settings → Policies → Shipping policy 全文替换（英文原文见右图，可直接复制）；Refund policy 删掉模板段落（perishable goods / flowers / hazardous），写清 30-day returns for unworn items、free return label for US、Final Sale items are marked on the product page（若决定促销品可退则删此句）。
2
全站邮箱统一 hello@alvaura.com；回复时效统一 within 24 hours (Mon–Sat)；/pages/shipping-returns 与 FAQ 的运费数字改成 $7.90 / $19.90。
✓
验证：页脚 Shipping policy、Refund policy、FAQ、Shipping & Returns 四页的运费、关税、退货天数、邮箱完全一致；结账页运费与之相符。

5. 启动真实评价体系：已验证标记 + 买家图

现在

280 条评价没有一条"已验证购买"、没有一张买家图，"Store reviews (0)"。

改成这样

真订单邀评后的样子：每条带 "✓ Verified Buyer · 购买的材质/尺码"，带图评价优先展示，Store reviews 有数。

1
Judge.me → Settings → Review Requests：开启自动邀评，发货后 14 天发送（定制款 21 天）；开启 Photo/Video reviews 与 Coupon for reviews（带图评价送 10% 回购码）；开启 "Show verified badge" 和 "Show product variant"。
2
现有 280 条：确认来源。若为导入，Judge.me 里保留但不在首页/卡片引用其总数；真订单评价累积到 30+ 条后再开卡片徽章。
3
注册 Trustpilot 免费商家账号（Judge.me 可同步），页脚加徽章。
✓
验证：30 天后详情页出现带 "Verified" 标记的评价，且至少 20% 带图。

6. 详情页：规格标签 + 发货日期行 + "一起买"套装块

现在

① 价格旁没有石头大小；② 加购按钮下没有发货日期和"关税已含"；③ 决定"值不值"的数字全在收起的折叠栏里。

改成这样

四个规格标签放在价格下方；加购按钮下一行绿字承诺；再下面是"Complete the stack"套装块（主石戒 + 2 叠戴戒，$497 → $422）。

1
Settings → Custom data → Products 建两个 metafield：stone_spec（"8 mm · 2.6 ct lab-grown sapphire · 2.5 μm 14k vermeil · 1.5 mm band"）、lead_time（"Ready to ship" / "Made to order · 7–15 days"）；CSV 批量导入 54 款。
2
主题编辑器 → Product → Product information：Price 下方加 Text 区块绑定 stone_spec；Buy buttons 下方加 Text 区块 "Ships by {日期} · Duties included · 30-day returns · 2-year warranty"；Details & Dimensions 折叠改默认展开。
3
套装块见第 7 条（Shopify Bundles）。删除 "THE ALVAURA DIFFERENCE" 区块里孤立的颜色副标题。
✓
验证：手机打开任一彩宝戒，不滚动就能看到毫米、克拉、发货时间三个信息。

第二档 · P1（1–2 个月）

7. Complete the stack 套装 + Color Stack SKU

改成这样

套装块位置：加购按钮和三个信任图标之间。主石戒 + 2 款叠戴戒，整体减 15%，一键加购。

1
装 Shopify Bundles（免费）：为每款彩宝主石戒建 1 个 "Complete the stack" 套装（主石戒 + 2 款叠戴戒，减 15%），套装商品挂在主石戒详情页加购按钮下方（主题编辑器 Product 区块 → 加 "Bundle" 区块或用 Bundles 的嵌入块）。
2
另建 5 个独立套装商品 "The Mint Stack / The Lagoon Stack / The Paraiba Stack / The Padparadscha Stack / The Cornflower Stack"，各拍一张三戒叠戴实拍，放进 Best Sellers 集合和首页 "The Art of Stacking" 区块。
✓
验证：30 天后看 Shopify Analytics "Average order value"，目标从单件均价约 $250 提到 $300+。

8. 购物车抽屉：两档进度条 + 推叠戴戒 / 礼盒

现在

加购后抽屉只有商品和结账按钮，进度条到 $150 就说"已免运"，没有下一步推动。

改成这样

进度条改成"已免标准运费 · 再加 $41 免快递"；商品下方推 2 款叠戴戒 + $15 礼盒，各带 ADD。

1
Ella 主题 Cart drawer 设置：进度条改两档 "Free standard shipping at $150 ✓ → Free express at $300"；开启 "Cart recommendations"，推荐来源设为叠戴戒集合（$89–119）。
2
已装的 AI Cart Max / Discos BOGO 实测没有出现内容——二选一保留并配置，或卸载以减轻页面加载。
3
建 Gift box $15 商品作为抽屉一键加购（现在的免费小盒评价里已被夸，付费升级版做礼盒 + 手写卡）。

9. 系列页卡片：角标 + 石头尺寸 + 评分

现在

卡片只有名字和价格，没有评分星、没有标签、没有石头尺寸。

改成这样

左上角角标（Best Seller / Ready to Ship / New），名称下一行石头尺寸，再一行评分和条数。

1
Judge.me → Widgets → Preview Badge → 开启 "Show on collection pages"（真评价累积到 30+ 后再开）。
2
商品打 tag：bestseller（按销量前 8）、new（90 天内）、ready-to-ship；Ella 主题 Product card → Badges 读 tag 显示角标。
3
卡片副标题显示 stone_spec 的前半段（"8 mm · 2.6 ct"）。

10. 手机固定加购条，关掉压内容的悬浮组件

现在

滚过加购按钮后，屏幕底部是 5 格站内导航，没有加购入口；悬浮球压在标题上。

改成这样

底部固定加购条：缩略图 + 名称 + 价格/尺码/发货日期 + 黑色 ADD TO CART；工具栏和悬浮球撤掉。

1
Ella 主题 Theme settings → Product page → 开启 Sticky add to cart（mobile）。
2
Theme settings → Mobile toolbar：关闭或只在首页显示。
3
Tolstoy 后台：关闭 "return visitor bubble"；"Shop with AI" 改为页脚链接 + 详情页折叠区一行；主题关闭右侧 "recently viewed / share" 悬浮按钮。
✓
验证：手机打开详情页滚到底，屏幕底部始终有 ADD TO CART；首页类目图块文字不被任何气泡遮挡。

11. 详情页加 "Why it's real" 对比表 + 镀层分层图

改成这样

位置：三个折叠栏之下、买家秀之上。四栏表回答"是不是真的、为什么 $259"；三层图把 2.5 微米讲成一眼看懂的截面。

1
主题编辑器 → Product → 在 Collapsible rows 之后加一个 Rich text / Custom liquid 区块，贴入对比表（HTML 见下）与分层图（三个色块 div 即可，不用做图）。
2
对比表内容：What it is（Real sapphire crystal, grown / Real sapphire, mined / Silicon carbide / Zirconium oxide）· Hardness（9 / 9 / 9.25 / 8–8.5）· Where the color lives（In the crystal — never fades / In the crystal / Mostly colorless / Dyed, can dull）· 2.6 ct in 14k vermeil（$259 / $2,000+ solid gold / — / ~$40）。
3
分层图三行：2-hour silica shield · salt-water tested / 2.5 μm solid 14k gold — about 100× thicker than flash plating (0.02 μm) / 925 sterling silver core。文字全在 Our Materials 页已有。

现在

"Free shipping / 30-Days Returns / 2-Year Warranty / Klarna" 在首页倒数第二区（滚动 4,300 像素后）。

改成这样

信任条紧跟 Most Loved 之后出现，四条改成带数字的：关税已含 / 30 天免费退 / 2.5 μm 包金 · 2 年保修 / 真培育蓝宝石 · 2–4 克拉。

1
主题编辑器 → 首页 → 把 "Multicolumn / Icon bar" 区块拖到 Featured collection（Most Loved）之后；四条文案替换为上图。

首页加文字 H1（Slideshow 标题设为 H1）；页面标题改 "Sapphire & Gemstone Rings, Lab-Grown | Alvaura"；商品图和类目图补 alt。
